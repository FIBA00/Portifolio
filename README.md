# Fraol — Portfolio

Personal portfolio site. React + Vite, Tailwind v4, React Router, React Query for live GitHub data.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- React Router v7
- TanStack Query (live GitHub repo feed)
- Deployed on Vercel

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/pages` — Home, Projects, About, NotFound
- `src/components` — NavBar, Hero, GithubStats, Footer
- `public` — favicon, robots.txt, sitemap.xml
